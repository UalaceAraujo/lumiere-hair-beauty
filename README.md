Lumiere Hair & Beauty

Modern web application built for luxury hair salons, featuring scroll-driven animations and an embedded administrative dashboard (CMS).

Features

Scroll-Driven Animations: Parallax and expansion effects using Framer Motion.

Manager Dashboard (CMS): Password-protected administrative area for complete platform management.

Theme Toggle (Dark/Light): Instant switching between sophisticated dark mode and clean light mode.

Text & Typography Management: Real-time editing of titles, slogans, about sections, and contact information.

Service Catalog & Image Upload: Add, edit, or remove services and upload images directly from your computer with automatic canvas optimization.

Booking System & WhatsApp: Client reservations with direct WhatsApp confirmation links.

Backup & Restore: Export and import site configurations in JSON format.

Technologies

React 18 + Vite

Tailwind CSS

Framer Motion

Lucide React

Local Development

npm install
npm run dev


Admin Access

Click the lock icon in the top navigation bar.

Enter the default password: lumiere2026 (can be changed inside the dashboard).

Deployment to Hostinger

npm run build


Upload the contents of the dist folder to the public_html directory.
